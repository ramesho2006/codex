# Codex Workspace

This repository is the canonical working directory for Codex projects and chat artifacts on this PC.

Local root:

```text
D:\Codex
```

Current project folders:

```text
Codex Prompts
JStockGenie
```

After a PC reset, restore this workspace by cloning the remote repository back to:

```powershell
git clone <remote-url> D:\Codex
```

Note: only files committed and pushed to the remote repository can be restored from Git. Any Codex app internal thread history that is not saved as files in this repository will not be recoverable from Git.
