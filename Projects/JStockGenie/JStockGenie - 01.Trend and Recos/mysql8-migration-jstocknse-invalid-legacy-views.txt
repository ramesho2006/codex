MySQL 8 migration audit - jstocknse legacy views not recreated
Date: 2026-08-17

The jstocknse schema was copied from MySQL 5.7 to MySQL 8.0.
All base tables, table data, functions, and procedures were copied.

The following views exist on the MySQL 5.7 source but are already invalid
when queried on the source. MySQL 8 could not recreate them as valid views
because their definitions depend on missing/invalid view, table, or column
references.
