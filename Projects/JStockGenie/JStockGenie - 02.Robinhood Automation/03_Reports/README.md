# Reports

Dated weekly and dry-run outputs live here.

## Folders

- `EQT/YYYYMMDD` - Agentic equity swing basket outputs.
- `ETF/YYYYMMDD` - ETF growth/dividend basket outputs.
- `Options/YYYYMMDD` - manual-only weekly options recommendations.
- `DryRuns/YYYYMMDD` - practice runs where no orders are reviewed or placed.

Keep dated folders intact so weekly history remains auditable.
